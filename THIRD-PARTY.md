# Third-party code

One dependency is vendored rather than fetched at runtime, because the whole point of this app
is that a printer should not need a CDN to print.

**`web/vendor/qrcode.js` — `qrcode-generator` 1.4.4, by Kazuhiko Arase**

MIT licensed, vendored **unmodified**, with its licence header retained at the top of the file
and a copy of the licence in `web/vendor/qrcode.LICENSE.txt`. Used to build the QR matrices that
`web/codes.js` turns into printer dots.

The word "QR Code" is a registered trademark of DENSO WAVE INCORPORATED; this project uses the
term descriptively, as the specification's own documentation does.

Everything else in this repository is original. The Code 128 symbol table in
`web/vendor/code128-table.js` is generated by `tools/make-code128-table.py` from the
`python-barcode` package, which is also MIT licensed — it is an encoding table from
ISO/IEC 15417, and the generator exists precisely so the table is not transcribed by hand.
The Code 128 checksum and symbol selection are implemented here; `python-barcode` is only used
in the tests, as an independent implementation to compare against. See the licence of this
repository in [LICENSE](LICENSE).

Connection failed
  • Disconnect the printer from anything else first — a BLE printer accepts one connection, and a phone's Bluetooth settings page counts as one.
  • Make sure the printer is awake (tap its button) and not mid-print.
  • Toggle Bluetooth off and on, then retry.
  • Press Connect again: these clone modules often refuse the first attempt.

    What this page does and does not do

    Everything happens locally in your browser: no server behind this page, no analytics, no account, no storage beyond your own device. The only network requests are the ones that loaded these files. Installed as an app it keeps working with the network off.

    The protocol was reverse engineered from the vendor app com.lailaixiong.funnyprint 2.8.1, then cross-checked against an independent, hardware-validated implementation of the same printer family, and verified on real hardware. PROTOCOL.md records every byte and where it came from, including the two bugs that cross-check found.

    The QR encoder is qrcode-generator (MIT, Kazuhiko Arase), vendored rather than loaded from a CDN so this page never calls out. Code 128 follows ISO/IEC 15417 and is checked byte-for-byte against an independent implementation.

    The vendor app also wants location, phone state, camera, advertising ID, the whole Firebase + Facebook analytics stack, and uploads label images and photo cutouts to api.dolewa.com. Printing needs none of that.

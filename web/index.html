Print settings

If the grey ramp on the test page band-steps badly, dithering off plus a threshold of ~110–140 usually prints cleanest text.

What this page does and does not do

Everything happens locally in your browser. There is no server behind this page, no analytics script, no account, no storage: close the tab and nothing of yours is kept. The only network request the page can make is the one that loaded these files in the first place.

The printer protocol here was reverse engineered from the vendor app com.lailaixiong.funnyprint 2.8.1 — see PROTOCOL.md in the project for the byte-level details and where each one came from.

The vendor app additionally wants location, phone state, camera, advertising ID, the whole Firebase + Facebook analytics stack, and uploads label images and photo-cutout jobs to api.dolewa.com. Printing itself needs none of that.
